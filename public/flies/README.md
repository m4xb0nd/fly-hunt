# Рисунки для игры

Положите сюда свои файлы РОВНО под такими именами — код уже ссылается
на эти пути, ничего в коде менять не придётся.

```
public/flies/
├── normal-fly.gif        анимация полёта обычной мухи
├── golden-fly.gif        анимация полёта золотой мухи
└── death/
    ├── normal-1.png       кадры смерти обычной мухи
    ├── normal-2.png        (можно 1, можно 10 штук —
    ├── normal-3.png         просто допишите путь в массив
    ├── golden-1.png       кадры смерти золотой мухи
    └── golden-2.png
```

Чтобы добавить или убрать кадр смерти, откройте
`src/game/flyAssets.ts` и отредактируйте массив `deathFrames`
у нужного вида мухи (`normal` или `golden`) — размер массива
может быть любым, код сам выбирает случайный кадр из того,
что там перечислено.

Пока файла по нужному пути нет (или он не загрузился), на поле
вместо картинки показывается эмодзи-заглушка (🪰 / ✨), так что
игру можно тестировать уже сейчас, без готовых рисунков.
