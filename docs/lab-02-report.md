# Отчёт по лабораторной работе №2

Проект «Охота на мух»

## 1. Название проекта и цель главной страницы

Проект называется «Охота на мух». Это браузерная игра: мухи вылетают с краёв
игрового стола, их нужно прихлопнуть мышкой. Главная страница выполняет две
задачи. Во-первых, объясняет правила и открывает игру. Во-вторых, показывает
сводку и список последних пойманных мух. Эти данные пока берутся из mock-источника,
а не с сервера.

## 2. Описание верстки

Главная страница состоит из трёх частей:

- шапка (`Header`): название приложения с иконкой и кнопка «Играть»;
- блок-приветствие (`menu__hero`): заголовок, краткие правила и кнопка «Начать игру»;
- блок статистики из трёх карточек (`StatCard`): число пойманных мух в истории,
  лучшая реакция и рекорд очков, который хранится в браузере;
- блок истории (`menu__history`): список карточек пойманных мух
  или надпись «Загрузка...», пока данные не пришли.

Вкладки навигации в шапке убраны, потому что второй страницы «Статистика»
и «История» пока нет. Отдельные маршруты для них не сделаны.

## 3. Mock-данные и их поля

Файл `src/mocks/catches.ts` содержит массив записей `FlyCatch` и функцию
`getCatchesMock()`. Она возвращает `Promise` и через `setTimeout` с задержкой
800 мс отдаёт массив, имитируя ответ сервера.

Поля записи `FlyCatch`:

| Поле | Тип | Назначение |
|---|---|---|
| id | string | уникальный идентификатор |
| name | string | название или кличка мухи |
| notes | string | заметки игрока о сессии |
| hitsCount | number | сколько ударов понадобилось: обычная 1, золотая 3 |
| avgReactionMs | number | средняя скорость реакции, мс |
| dateCaught | string (дата) | дата поимки |
| difficulty | категория | лёгкая, средняя, сложная или золотая |
| isGolden | boolean | признак золотой мухи |
| entrySide | категория | с какого края влетела муха: сверху, снизу, слева или справа |

## 4. Созданные компоненты

- `components/Header/Header.tsx` - шапка с названием и кнопкой игры;
- `components/CatchCard/CatchCard.tsx` - карточка одной пойманной мухи,
  получает данные через props (`catchItem`);
- `components/CatchList/CatchList.tsx` - список карточек, рендерит их через
  `.map()`, получает массив через props (`catches`);
- `components/Fly/Fly.tsx` - муха на игровом поле: показывает нужную картинку
  в зависимости от состояния и передаёт клики наверх;
- `components/FlyArt/FlyArt.tsx` - муха, искры и лужица, нарисованные в коде;
  нужны, пока в `public/flies` нет своих картинок;
- `pages/Home/Home.tsx` - главная страница, которая получает mock-данные
  и передаёт их в `CatchList`;
- `pages/Game/Game.tsx` - игровой экран: шапка с очками, поле, отсчёт и итоги раунда.

## 5. Где используется useState

В `pages/Home/Home.tsx`:

- `const [catches, setCatches] = useState<FlyCatch[]>([])` - массив записей,
  полученных из mock-источника;
- `const [isLoading, setIsLoading] = useState(true)` - флаг загрузки, пока данные не пришли;
- `const [bestScore] = useState(loadBestScore)` - рекорд очков из localStorage.

В `pages/Game/Game.tsx` и `game/useFlyRound.ts`:

- `const [state, setState] = useState<RoundState>(...)` - копия состояния раунда
  (фаза, мухи, всплывающие надписи, счёт), которую видит интерфейс;
- `const [aspect, setAspect] = useState(1)` - пропорции поля, от них зависит
  поворот нарисованных мух.

Состояние игры меняется каждый кадр, поэтому само игровое состояние хранится
в `useRef`, а в `useState` попадают только его копии. Так React не перерисовывает
страницу лишний раз внутри расчётов.

## 6. Где используется useEffect

В `pages/Home/Home.tsx` с пустым массивом зависимостей `[]` эффект запускается
один раз при открытии страницы:

```ts
useEffect(() => {
  getCatchesMock().then((data) => {
    setCatches(data);
    setIsLoading(false);
  });
}, []);
```

В `game/useFlyRound.ts` эффект запускает цикл `requestAnimationFrame`: каждый кадр
двигает мух, проверяет таймеры и обновляет состояние. При уходе со страницы цикл
останавливается через `cancelAnimationFrame`.

В `pages/Game/Game.tsx` эффекты предзагружают звуки и следят за размером поля
через `ResizeObserver`.

## 7. Правила игры

- Раунд начинается с отсчёта 3 секунды. Потом мухи вылетают с случайного края
  поля. Чем дольше идёт раунд, тем чаще появляются новые мухи.
- Обычная муха погибает от одного удара и приносит 10 очков. Золотая муха
  требует три удара и приносит 50 очков.
- Убитая обычная муха падает на «стол» (нижнюю линию поля). Её можно схватить
  мышкой и переложить. Если отпустить её в движении, она летит по инерции
  и отскакивает от стенок и стола.
- Золотая муха после последнего удара вспыхивает искрами и исчезает. Её нельзя
  ни схватить, ни ударить.
- Раунд не имеет таймера. Его заканчивает кнопка «Стоп». После этого открываются
  итоги, а рекорд очков сохраняется в localStorage.
- Перетаскивание мухи очки и счётчик поимок не меняет: поимка засчитывается
  в момент удара.
