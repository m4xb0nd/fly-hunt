# Отчёт по лабораторной работе №2

Проект «Охота на мух»

## 1. Название проекта и цель главной страницы

Проект — «Охота на мух», игровой трекер охоты на мух с учётом пойманных
экземпляров. Цель главной страницы — показать пользователю, что это за
приложение, и вывести сводную статистику и список последних пойманных мух,
полученных из mock-источника.

## 2. Описание верстки

Главная страница состоит из:

- шапки (`Header`) с названием приложения и навигацией по будущим разделам
  (`/`, `/game`, `/catches`, `/stats`);
- блока с заголовком и коротким описанием приложения;
- сводного блока с двумя показателями: количество пойманных мух и лучшая
  скорость реакции;
- блока с карточками пойманных мух (`CatchList` → `CatchCard`).

## 3. Mock-данные и их поля

Файл `src/mocks/catches.ts` содержит массив записей `FlyCatch` и функцию
`getCatchesMock()`, которая возвращает `Promise` с задержкой 800 мс через
`setTimeout`, имитируя ответ сервера.

Поля записи `FlyCatch`:

| Поле | Тип | Назначение |
|---|---|---|
| id | string | уникальный идентификатор |
| name | string | название/кличка мухи |
| notes | string | заметки игрока о сессии |
| hitsCount | number | сколько ударов потребовалось: обычная 1, золотая 3 |
| avgReactionMs | number | средняя скорость реакции, мс |
| dateCaught | date (string) | дата поимки |
| difficulty | категория | лёгкая / средняя / сложная / золотая |
| isGolden | boolean | признак редкой «золотой» мухи |
| entrySide | категория | с какого края экрана влетела муха: сверху / снизу / слева / справа |

## 4. Созданные компоненты

- `components/Header/Header.tsx` — шапка страницы с названием и кнопкой игры;
- `components/CatchCard/CatchCard.tsx` — карточка одной пойманной мухи,
  принимает данные через props (`catchItem`);
- `components/CatchList/CatchList.tsx` — список карточек, рендерит их через
  `.map()`, принимает массив через props (`catches`);
- `pages/Home/Home.tsx` — страница, которая получает mock-данные и передаёт
  их в `CatchList`.

## 5. Где используется useState

В `pages/Home/Home.tsx`:

- `const [catches, setCatches] = useState<FlyCatch[]>([])` — хранит массив
  записей, полученных из mock-источника;
- `const [isLoading, setIsLoading] = useState(true)` — хранит состояние
  загрузки, пока данные не пришли.

## 6. Где используется useEffect

В `pages/Home/Home.tsx`, с пустым массивом зависимостей `[]`, эффект
запускается один раз при открытии главной страницы:

```ts
useEffect(() => {
  getCatchesMock().then((data) => {
    setCatches(data);
    setIsLoading(false);
  });
}, []);
```

Пока `isLoading === true`, вместо списка показывается текст «Загрузка...».
