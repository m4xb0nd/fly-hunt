# Охота на мух

Браузерная игра: мухи вылетают с краёв стола, их нужно хлопнуть кликом мыши
до конца раунда. Золотые мухи дают больше очков, но их нужно ударить трижды.
История пойманных мух пока берётся из mock-данных (`src/mocks/catches.ts`).

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # проверка типов и сборка
npm run lint     # линтер (oxlint)
```

## Как играть

- **Меню** - история пойманных мух, лучшая реакция и рекорд очков.
- **Очки** - обычная муха 10 очков (один удар), золотая 50 (три удара).
- **Убитая муха** падает на стол. Её можно схватить мышкой и переложить.
  Очки и счётчик поимок от перетаскивания не меняются: поимка засчитывается в момент удара.
- **Точность** - попадания по мухам к общему числу кликов. Клик мимо мухи - промах.
- **Рекорд** хранится в localStorage браузера.

## Звуки

Звуки взяты из набора Hanna-Barbera cartoon sound FX и сохранены в `public/sounds/` в mp3:

| Файл | Когда звучит | Исходный файл из набора |
|---|---|---|
| `hit.mp3` | попадание по мухе (муха ещё жива) | 05 Freds Hard Head Hit |
| `kill.mp3` | муха убита; у золотой звук выше | 17 Ba-Wong |
| `miss.mp3` | клик мимо мухи | 27 Bloop |
| `tick.mp3` | каждая цифра отсчёта (3, 2, 1) | 20 Bilp |
| `start.mp3` | старт раунда | 90 Xylophone |
| `end.mp3` | время вышло | 08 Fred Drops the Ball |

Звуки обрезаны по тишине и сжаты ffmpeg. Логика воспроизведения в `src/game/sound.ts`.

## Стиль

Оформление в духе Doodle Jump: тетрадный лист в клетку, рисованные от руки рамки,
зелёные платформы, маркерные выделения.

- Шрифт **Pangolin** (OFL, файл и лицензия в `src/assets/fonts/`) используется везде.
- Рамки рисуются псевдоэлементом с SVG-фильтром `#sketch` (определён в `index.html`).
  Чтобы элемент получил такую рамку, добавьте ему класс `ink-box` (или `btn` для кнопки).
- Цвета и размер клетки задаются переменными в `src/index.css`.

## Структура

```
src/
├── game/          игровая логика: раунд (useFlyRound), спавн, звуки, рекорд
├── components/    Header (шапка), Fly (муха на поле),
│                  FlyArt (муха, нарисованная в коде), CatchCard, CatchList
├── pages/         Home (меню) и Game (раунд)
├── mocks/         mock-данные истории
├── assets/fonts/  шрифт Pangolin и его лицензия
└── types/         типы мух, раунда и пойманных мух
public/flies/      картинки мух (необязательно, см. ниже)
docs/              отчёт по лабораторной работе
```

## Картинки мух

Файлы кладутся в эту папку под такими именами - код уже ссылается на эти пути:

```
public/flies/
├── fly.gif        анимация полёта обычной мухи (есть)
├── golden-fly.gif        анимация полёта золотой мухи (пока нет, сейчас берётся обычная с подсветкой)
├── sparks.gif            искры после гибели золотой мухи;
│                         гифка должна уложиться примерно в 0.8 с - потом муха исчезает
└── death/
    ├──death1.png      кадры смерти обычной мухи 
    ├── death2.png     
    ├── death3.png     
```

- Золотой мухи пока нет, поэтому она берёт `fly.gif` с золотистым фильтром.
  Когда появится `golden-fly.gif`, поправьте `flyingSrc` и уберите `flyingFilter`
  в `src/game/flyAssets.ts`.
- Чтобы добавить или убрать кадр смерти, отредактируйте массив `deathFrames`
  в том же файле. Код сам выбирает случайный кадр из перечисленных.
- Картинки не поворачиваются по направлению полёта, поэтому рисуйте персонажа
  так, как он должен выглядеть на экране.
- Пока кадра смерти нет, вместо мухи показывается лужица, нарисованная в коде.
- Если файла нет совсем, муха рисуется в коде (SVG).
